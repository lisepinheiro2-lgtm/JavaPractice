# ☕ Java – Exercices de consolidation

## 🎯 Objectif

Ce dépôt accompagne mon apprentissage de Java dans le cadre de ma reconversion professionnelle vers les métiers du développement logiciel et du test logiciel, avec pour objectif la QA Automation.

Après avoir découvert de nombreuses notions et syntaxes au cours du développement de mon projet [GestionRemplacement](https://github.com/lisepinheiro2-lgtm/gestionRemplacement), j'ai décidé de prendre le temps de les consolider avant de poursuivre son développement.

## 🧠 Ma méthode d'apprentissage

L'objectif n'est pas simplement de réussir un exercice, mais de comprendre la logique et les syntaxes utilisées pour pouvoir les réemployer de manière autonome.

- Résoudre les exercices par moi-même, sans solution fournie à l'avance.
- Combiner progressivement plusieurs notions déjà rencontrées.
- Identifier et comprendre mes erreurs.
- Revenir régulièrement sur les notions moins bien assimilées.
- Augmenter progressivement la difficulté.

## 💻 Notions travaillées

Les exercices pourront notamment porter sur :

- Les collections et leur manipulation.
- Les dates, heures et durées avec l'API.
- Les comparateurs et le tri.
- La lecture et l'écriture de fichiers CSV.
- La programmation orientée objet.
- La gestion des exceptions.
- Les tests unitaires avec JUnit.

Cette liste évoluera avec mes besoins et mes progrès.

## 🚧 État du dépôt

Ce dépôt est un espace d'entraînement en évolution.

Les exercices reflètent mon niveau au moment où je les réalise, y compris mes difficultés et les améliorations apportées au fil du temps.

**L'objectif : comprendre, consolider, pratiquer et progresser.** 😊
